# Support

Osira API is maintained by its open-source community on a best-effort basis.

Before asking for help:

1. Read the README and contribution guide.
2. Search existing issues for the same question or error.
3. Confirm the problem still occurs with the latest supported code.

If you still need help, open an issue using the most relevant template and
include your PHP version, operating system, installation method, relevant
configuration with secrets removed, reproducible steps, and the complete error
message.

Bug reports and support requests are public. Remove credentials, tokens,
private URLs, personal data, and other sensitive information before posting.
Security vulnerabilities must be reported privately according to
[SECURITY.md](SECURITY.md).
